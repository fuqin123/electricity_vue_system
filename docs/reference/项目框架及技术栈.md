## 1. 项目概况

| 项       | 内容                                                         |
| -------- | ------------------------------------------------------------ |
| 项目名称 | 能源产效管理系统                                             |
| 系统定位 | 公司内网部署，进行数据中心面板展示                           |
| 架构模式 | 前后端分离（Django REST API + Vue3 SPA）                     |
| 视觉规范 | 数据中心展示界面整体参考（E:\能源产效管理平台\frontend）中的前面界面，但为了现代化技术栈和美化以及流畅性使用vue3开发。后台管理数据信息日志展示界面以（E:\能源产效管理平台\Volcengine_design）源力设计系统（Yuanli Design System，来自 `Volcengine_design/`）和Element Plus进行实现。 |
| 设计基准 | 数据中心展示界面设计基准参考：E:\能源产效管理平台\frontend                                                                                                                                           管理界面设计基准：主色源力蓝 `#1664FF`、4px 栅格、48px 顶栏、32px 操作高度、**仅亮色模式** |
| 本期范围 | **仅框架**：路由 / 菜单 / 页面骨架 / 跳转可通；所有业务函数留空 |
| 开发环境 | Windows（本机）                                              |
| 部署环境 | 暂定                                                         |

### 前端

| 应用               | 选型                                                         |
| :----------------- | :----------------------------------------------------------- |
| 大屏 `frontend/apps/screen` | Vue 3.5 + Vite + ECharts + Pinia + Vue Router(hash) + VueUse + SCSS |
| 后台 `frontend/apps/admin`  | Vue 3.5 + Vite + **Element Plus** + ECharts + Pinia + Vue Router(history) + VueUse + SCSS |
| 表单               | admin 用 Element Plus Form + 校验；或用 `vee-validate` + zod |
| 表格               | Element Plus Table（虚拟滚动）；大数据量上 `vxe-table`       |
| 共享               | `frontend/packages/shared`：TypeScript 类型、API SDK、tokens.scss     |
